# Phase 24：逐属性种子选择与持续探索验证

日期：2026-11-17

仓库 `main` 基线：`a0adcafdf6af86e17805d4076fb38ee371753abb`（与本地 `main` / `origin/main` 一致，Phase 23）

## 结论

- Phase 10 Request `independent_dual` 的 8 条候选，经规范化交易序列去重为 4 条；严格 Anvil 回放后，得到 **3 条真正有效且彼此不同的逐属性种子**，来自 4 个不同源属性。其余 1 条独特序列因内部调用意外回滚而判无效，仍保留在审计记录中。
- G1 全部加载有效种子后，后续新增 LCOV 源码行均值为 142.2；G0 原生 Echidna 均值为 491.0。配对比较 G1 五次均少于 G0，均差 -348.8 行。G1 最终总唯一指令均值略高 154.6，但仅 2/5 配对更高、1 平、2 低，不能视为稳定探索增益。
- G2 覆盖贪心选择与 G3 固定随机选择在冻结时抽到同一对种子，五组的全部覆盖及指令结果完全相同。因此本轮没有证据证明覆盖贡献选择优于同数量随机选择，也没有达到预注册的稳定优势标准。
- 20/20 次正式运行都在 500 次测试限制处完成。相对各组独立回放 LCOV，20/20 次都新增源码覆盖行；但在预先指定的 Request 驱动与 wrapper 目标代码区间内，G1/G2/G3 后续新增覆盖均为 0 行。
- **建议停止基于反馈的种子调度方向，不安排追加调参实验。** 本轮同时未满足 G1 后续探索增益和 G2 对 G3 稳定优势两项预注册门槛。

## 种子来源、去重与逐笔回放

来源清单保留 8 条候选记录（两个独立重复 × 四个源属性），原始 Phase 10 状态均为 `executable`。对 Request ABI 下的规范化有序交易序列计算 SHA-256 后，8 条记录归并为 4 个不同序列。逐条核验原始 corpus 文件存在、文件 SHA-256 与清单相符，且序列与 Agent 交易记录经当前 Request ABI 编码后相同。重复别名没有删除。

有效性要求同一 Request Harness 成功部署，全部 16 个初始属性为真；每笔交易须有成功的外层收据、callTracer 和 prestateTracer 证据、可观察到持久存储槽及公开 getter 状态变化，且不能出现未预期的内部调用回滚。属性违反会作为结果记录，本身不自动使一个可执行种子失效。

## 组别与独立回放覆盖

独立回放只加载指定种子并以 testLimit=0 运行；G0 用空 corpus 建立回放基线。每条有效序列相对空回放分别增加 285、286、249 条 LCOV 源码行；三条合并覆盖 386 行、13,787 条唯一指令。空 corpus 为 32 行、1,980 条唯一指令。G1 全部种子的源码行并集也是 386 行，说明第三条有效种子没有扩大该集合的并集覆盖。

### 回放以外的覆盖及目标路径

各正式运行最终 LCOV 减去同组独立回放 LCOV 后，G0 新增 458–505 行，G1 新增 107–151 行，G2/G3 新增 107–151 行。由此可以确认 Echidna 的后续变异在源码行覆盖层面确实到达了回放集合以外的代码。LCOV 记录的是源码行，不是路径 ID；因此这里只把它称为“新增源码行覆盖”，不把它夸大为精确的唯一控制流路径数。

冻结的目标相关区间包含 Harness 的 authorize/capture/charge 驱动，以及 wrapper 的 authorize/capture/charge 路径。G0 的种子回放在这些区间均为 0 行，后续模糊测试均值分别新增 23.0、7.6、24.0、99.0、18.8、69.0 行。G1/G2/G3 的独立回放已分别覆盖 Harness 23/8/24 行与 wrapper 99/26/69 行；三组正式运行在这六个区间中均未新增覆盖行。故全局确有回放以外探索，但未证明种子能帮助后续模糊测试继续拓展本轮指定的目标代码区间。

## 验收问题与判断

1. **现有多少条真正有效且彼此不同的逐属性种子？** 3 条。原始 8 条记录归并为 4 条不同序列，其中 3 条严格回放有效；记录来源涉及 4 个属性 ID。不是 7 条（那是通过的源记录数，含重复）。
2. **全部种子直接合并是否优于原生 Echidna？** 否。G1 后续新增行远低于 G0，且 0/5 配对胜出。最终指令均值略高但配对不稳定，不能抵消该结果。
3. **基于覆盖贡献选择是否优于同数量随机选择？** 本轮没有证据。G2/G3 抽到相同两个种子，正式结果逐项相同。
4. **后续变异是否真正产生了回放阶段以外的新路径？** 是，严格可确认的是 20/20 次均新增源码行覆盖；LCOV 不提供唯一路径 ID。对指定的目标代码区间，种子组后续均无新增行。
5. **是否值得继续开发基于反馈的种子调度算法？** 不值得。G2 未稳定胜 G3，G1 未产生有意义的后续探索增益，按预注册门槛停止该方向，不追加调参实验。
