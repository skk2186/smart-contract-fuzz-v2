# Phase38：跨交易约束补全的独立真实合约最小验证

日期：2026-11-21。冻结基线：`main` @ `20671285ae1a59ec93d8ba4b4da8baafce3d6aab`。本报告依照预先冻结的最多 4 个候选顺序完成独立性与工程资格筛选。四项均不满足全部准入条件，因此按停止规则不运行正式 G0/G1/G2，也不继续添加候选。

## 1. 目标、冻结与范围

唯一研究目标是验证 Phase37 的跨交易前置约束绑定能否在未参与方法开发的真实合约上提高有效序列与目标状态到达能力。本轮不修改 Slither 属性依赖分析、Agent A/B、E2、E3、Phase36 门控或 Phase37 绑定，不改真实合约和原生属性，不新增 Agent，不进入 Phase39。

运行前重新核验分支 `main`、HEAD `20671285ae1a59ec93d8ba4b4da8baafce3d6aab`。受跟踪工作区干净；既有未跟踪目录 DODOCrossChain、Strata、VeryLiquidVaults、eBTC_BSM 保留。只读检查发现 Strata 内有未跟踪 `foundry.lock`，DODOCrossChain 的嵌套依赖子模块状态为 modified；本轮没有改写或暂存这两项。

方法和环境已在项目筛选前冻结，包含 Slither/Agent A/B/E2/E3/门控/绑定源码 SHA-256、运行器和工具版本哈希、最大序列长度 8、候选考虑预算 24、最多保留前缀 4、扩展随机种子基数 20261120、绑定方案上限 1，以及 Echidna `testLimit=500`、配对随机种子 3801/3802/3803。冻结记录见[方法冻结 JSON](../func/测试过程/跨交易属性状态依赖审计/结果/Phase38-20261121/00-Phase38方法冻结.json)。16 项方法源码哈希校验全部匹配冻结值。

候选顺序在筛查前冻结为 Hokusai、Kink、Strata、DODOCrossChain；最多审查 4 个，达到 2 个合格项目即停止。Phase37 的 Wallet、B/C/D 诊断 Harness、Pigfox 均不作为留出项目。

## 6. 结论与阶段建议

本轮必须在给定选项中选择 **B：方法能够运行，但独立收益尚不充分，需要进一步确认**。Phase37 证明了原型能在开发诊断集运行并达到其冻结目标；Phase38 没有找到同时满足独立来源、可追溯许可证/版本、可复现多交易依赖及同 Harness Anvil/Echidna 对照条件的留出项目，所以独立收益仍未得到测试，更没有观察到可归因的正向或负向留出结果。

**不建议依据 Phase38 扩大到论文正式样本规模。** 后续若另行立项，应先获得来源、commit、许可证和原生 Harness 齐全、且能在 Anvil 与 Echidna 保持同一 actor 语义的真实项目；本报告不启动该后续工作，也不进入 Phase39。
