## 一、范围与结论

本阶段只重审 Phase43 的 Agent 输出格式和 Phase44 已有候选反馈，不调用新的 Agent API，不重新回放100个任务，不运行正式或快速 Echidna fuzz，也没有修改合约、Harness、属性或执行语义。唯一生产逻辑改动是：当 ABI 数组参数被模型包成字符串时，用 JSON 解析器解包，之后仍走既有类型、范围和交易数量校验。

主要结论：Phase43 中74个数组字符串响应均可恢复为通过现有严格校验的候选，但这仅证明序列合法，不证明序列可执行。Phase44 的1572条扩展候选中，直接属性操作数 bug 均有反馈观察，却没有一条向原生属性违反边界推进。每任务保留4条、候选池和输入相同的离线配对排序选择了完全相同的集合（100/100）。因此本轮没有证据支持属性状态评价优于原评价，也没有启动快速验证。

### 3.2 初始序列不足的原因

Phase43 的最大长度配置是8笔，但 Agent A 实际只规划1至2步，没有触及8笔程序上限；因此这些 A 规划偏短来自模型规划不足，而不是程序校验把较长计划截短。Phase44 的既有可达性搜索显示目标路线最少约需18至64笔，故8笔上限又是独立的硬性不可达因素。74条格式错误解释了候选为何没有进入原校验流程，不能据此推断 Agent 不理解合约。另有1项确为 Agent A 与 B 的交易数量不一致。恢复格式不修复规划深度，也不自动解决原7项执行回滚。

## 四、Phase44 属性状态与覆盖反馈审计

### 4.1 静态属性状态和反馈可观察性

Olympia 的100项显式属性均直接读取 Maze.bug，原生谓词为 return !bug。静态动作上下文还列出 Maze.stop 和 Maze.next_cell 等守卫、前置条件及闭包状态；它们是可解释的间接执行条件，不等同于属性数值距离。Phase44 逐候选反馈记录能观察 bug 与 echidna_noBug，各1572条（开发集252、评估集1320）；没有记录 stop 或 next_cell 的 getter 值，故这两个间接状态在逐候选反馈中的未知数各为100项任务。不能把未观察到的状态推断成未发生变化。

直接状态采用属性源码方向分类，而非通用布尔距离。1572条候选全部有 bug 观察，均为观察到状态但没有到达违反边界；账本包含1684条逐笔 getter 转移，全部为 bug=false→false，旧字段 property_related_state_changed 在1572条均为 false。未发现可支持“向违反属性方向推进”的候选，也未发现候选直接导致原生属性违反。直接操作数观察未知的候选为0，但间接前置状态的观察仍缺失。

### 4.2 可执行、覆盖、目标状态与 Echidna

- Phase44 的1572条候选中，856条 PyEVM 序列完整执行成功，716条未完整执行成功。
- 968条候选相对各自基线有源码覆盖增加；其中91条来自有 E1 种子的25项任务，877条来自没有 E1 的75项任务、相对于空种子基线。空集基线上的增加只说明候选首次带来可观察覆盖，不是超越已有种子的算法收益。
- Phase44 开发集启动门是 successful_coverage_gains > 0：至少有候选成功执行并在回放中增加源码行即可过门。E1 缺失任务的空集对照也能满足这个覆盖条件；此门不要求属性相关状态推进。
- 正式 G1/G2 fuzz 代码将所有 PyEVM 可执行扩展候选传入 seed_sequences，没有按属性进展筛选。对保存的686份 Phase44 Echidna 日志核对预期可执行候选数，686/686 加载数量匹配；对应每个任务/组的可执行候选数分布为0条50组、4条20组、5条4组、6条126组，所有注入候选的指纹随审计汇总归档。
- 单候选原生 Echidna 隔离日志中，1572项属性均报告 passing；其中1559条记录为加载并回放1条，13条加载了1条但在时限到达前回放数为0。因此后13条的 passing 不是该序列通过回放的证据。全部 Phase44 候选均没有观察到原生反例。
- Phase44 已有评估集正式结果是 G0 在15/84项任务发现反例，G1/G2各13/84；Phase45 未重新运行或改变这些结果。Phase44 的 G1/G2 结果没有超过 G0。

Phase44 候选生成/门控以成功执行和普通覆盖作为开发集开门条件，Phase44 正式种子注入保留全部可执行候选；审计不到实际用于排序或注入的属性进展信号。Phase37 绑定也没有补上这条链路：786条 G2 候选全部记录为没有匹配的跨交易约束，G1 的786条记录为机制未启用。Olympia 的属性直接读 bug，而既有交易状态读写分析没有提供精确的跨交易写读匹配，故 Phase37 绑定在此不适用。

## 六、停止决定与研究解释

依照冻结停止门，可靠属性进展任务数为0、配对选择变化为0，故未改造生产候选评分、E3状态反馈或前缀保留逻辑，也未启动快速验证。未运行四任务以内的 Olympia 验证、没有新 Echidna 比较组、没有新反例。用户要求的同样候选生成预算和运行预算只能在快速验证阶段检查，本阶段离线排序不把该指标伪装成 fuzz 效果。

本轮没有属性进展优势。已有属性直接操作数可以观察，但所有候选的 bug 状态都停留在安全值；能帮助判断中间阶段的 Maze.stop / Maze.next_cell 反馈缺失，候选池中也没有可用于排序的目标方向证据。Agent 初始计划只有1至2步，目标路线则至少18笔，seqLen=8限制此前确实阻断完整路线。当前证据更支持“短计划和中间状态反馈不足，候选不含目标方向推进”，而不能单凭候选评价器解释全部失败。建议保留通用数组解析修复与本轮负结果，暂不扩张属性评分；只有先在不泄露参考路线的前提下获得可观察、可独立核验的多阶段状态反馈，才值得重开小规模对照。该建议不代表论文贡献或泛化能力已成立。
