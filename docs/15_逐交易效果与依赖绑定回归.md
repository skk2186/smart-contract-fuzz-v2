# 逐交易效果与依赖绑定回归

本阶段只改通用验证机制和 Agent B 的参数契约，未调用 DeepSeek API，未新增 Agent、合约或大规模实验。输入固定为[既有种子核验](14_既有种子效用核验.md)中的 7 条阶段 A 种子；旧语料与旧对照结果未改写。

## 改动

回放器逐笔读取 Anvil 内部调用 trace、持久存储差异和 receipt 事件。新字段 `execution_class` 区分真实状态建立、显式声明的预期拒绝、意外内部回滚及无持久状态变化。若计划声明 `expected_outcome=state_change`，但没有存储变化，候选失败；只有显式声明 `rejection` 的内部回滚才可作为预期拒绝通过。历史种子没有该声明时保守判为意外回滚，不能凭函数名自动豁免。

Agent B 可把后续参数写成 `{ "from_transaction": 1, "event": "BatchCreated", "field": "batchId" }`。回放器只从已执行交易的唯一匹配事件字段取值，按目标 ABI 类型校验；无法唯一取得时标记 `dependency_unresolved`，把错误和已有事件反馈给 Agent B。历史种子已有明确依赖提示时也可按同名事件字段重新绑定；同名的前序输入（如 `actorId`）则校验复用。最终 Echidna 语料写入实际解析后的参数，而不是模型原先猜的值。

## 七条历史种子离线回归

| 属性 ID 前缀 | 原样回放 | 使用历史依赖提示 | 结果解释 |
|---|---|---|---|
| BeeStorage `0226` | 失败 | 失败 | 内部权限拒绝真实发生；旧种子未声明预期拒绝 |
| Hokusai `04c6` | 失败 | 失败 | 内部未授权 mint 拒绝真实发生；旧种子未声明预期拒绝 |
| BeeStorage `571d` | 有效 | 有效 | 内部价格存储槽改变 |
| Hokusai `a36b` | 有效 | 有效 | 一次性分配状态建立 |
| Hokusai `40b3` | 有效 | 有效 | mint、burn 两笔均有持久写入 |
| Kink `28d4` | 有效 | 有效 | add、yank 两笔均有持久写入 |
| BeeStorage `2c68` | 失败 | 有效 | 从 `BatchCreated.batchId` 绑定第二笔参数，topUp 从内部回滚变为成功，新增 8 个持久存储槽变化 |

对两条权限历史种子另做**反事实验证**：在副本中明确声明 `expected_outcome=rejection` 后，均被分类为 `expected_rejection` 并通过。该声明是对已核对的权限测试意图的测试输入，不表示旧 Agent B 曾输出过这个字段。BeeStorage `2c68` 的原始第二笔仍记录为失败；修正回放记录了从 `0x…01` 到事件中真实 `batchId` 的绑定。显式事件引用也已本地试验：正确引用可执行，引用不存在的事件会失败并进入修复反馈。

本次只验证 Anvil 执行与回放分类，没有重新运行 Echidna 覆盖对照，也不把修正种子的覆盖收益算进旧实验。下一步如需评估模糊测试收益，应在相同预算下重新比较修正后语料与原生 Echidna。
对已声明但没有可解析事件的对象 ID 依赖，本次机制只能保守报告缺少证据；存储槽变化本身也不能证明任意未声明的业务条件成立。
